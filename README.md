Приложение для автоматизации записи к врачу с модулем напоминанйи паицентам
Приложение для автоматизации записи к врачу с модулем напоминанйи паицентам – клиент-серверное desktop-приложение для автоматизации записи пациентов на приём к врачам и управления связанными медицинскими данными.
Проект разработан в рамках курсовой работы и предназначен для автоматизации основных процессов медицинского учреждения: записи и отмены приёмов, управления расписанием врачей, ведения медицинских записей и формирования напоминаний о предстоящих посещениях.
Приложение построено по клиент-серверной архитектуре. Пользователь взаимодействует с JavaFX-клиентом, который передаёт запросы серверу по TCP/IP. Сервер отвечает за обработку запросов, бизнес-логику, аутентификацию и авторизацию пользователей, работу с базой данных и выполнение фоновых задач.
В системе предусмотрено три роли – PATIENT, DOCTOR и ADMIN. В зависимости от роли пользователь получает доступ к соответствующей функциональности.
Для пациента основным сценарием является поиск врача, выбор свободного времени и создание записи. После создания записи система автоматически формирует напоминания о предстоящем приёме. Врач работает со своим расписанием и медицинскими записями пациентов, а администратор управляет пользователями, врачами, расписанием и системными данными.

Сервер принимает подключения на порту 5555, а обработка клиентских соединений выполняется параллельно. Логика приложения разделена на обработчики запросов, сервисный слой и слой доступа к данным.
Для работы с базой данных используется Hibernate ORM, а операции доступа к данным инкапсулированы в DAO. Для построения приложения применяются паттерны DAO, Command, Singleton, Builder, Observer и Strategy.
Технологический стек
Java 21 –> JavaFX 21 –> PostgreSQL 16 –> Hibernate ORM 6.4 –> TCP/IP –> Maven –> Junit 5
Для хранения данных используется реляционная база PostgreSQL. Она содержит связанные сущности пользователей, пациентов, врачей, специализаций, расписания, записей на приём, медицинских записей, напоминаний и журнала аудита.
Особое внимание уделено целостности данных: между сущностями определены внешние ключи, а критические действия пользователей фиксируются в журнале аудита.
В приложении реализованы аутентификация и ролевая авторизация. Пароли хранятся в виде хешей, пользовательские сессии идентифицируются уникальными токенами и имеют ограниченный срок действия.
Доступ к операциям контролируется на стороне сервера, а для работы с базой данных используются параметризованные запросы. Критические операции, включая создание и отмену записей, изменения медицинских данных и административные действия, регистрируются в audit_log.
Администратор может формировать отчёты по работе системы, включая загрузку врачей, посещаемость пациентов, эффективность напоминаний и активность пользователей. Результаты могут экспортироваться в CSV.
Для запуска требуется JDK 17+, PostgreSQL 14+ и Maven. После создания базы данных необходимо выполнить SQL-скрипт и настроить параметры подключения.
Сначала запускается сервер, после чего запускается JavaFX-клиент. Клиент подключается к серверу через localhost:5555.
Проект представляет собой учебное полнофункциональное приложение, разработанное для практического применения Java, SQL, клиент-серверного взаимодействия и принципов объектно-ориентированного проектирования.
В качестве дальнейшего развития рассматриваются интеграция с существующими медицинскими информационными системами, мобильный клиент, push-уведомления и расширение аналитических возможностей.
